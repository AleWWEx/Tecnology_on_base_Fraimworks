## Индивидуальный проект

**Название проекта:** Система организации дискуссионных клубов
(Discussion Club Management System).

**Структура модулей проекта:** `main.py` — точка входа, режимы работы и меню;
`clubs.py` — клубы; `topics.py` — темы дискуссий; `events.py` — мероприятия и
свободные места; `registrations.py` — регистрации и решение по заявке;
`storage.py` — работа с JSON-файлами; `analytics.py` — статистика;
`utils.py` — безопасный ввод, даты, идентификаторы. Всего 95 функций в восьми
модулях, между которыми логика распределена по смыслу: модули данных не
обращаются к файлам, файловый модуль не знает предметной области.

**Формат хранения данных:** четыре JSON-файла в каталоге `data/` — `clubs.json`,
`topics.json`, `events.json`, `registrations.json`. Каждый файл — список
словарей с полем `id`; даты мероприятий хранятся строками в формате
`ГГГГ-ММ-ДД` и преобразуются в объекты `datetime.date` при загрузке. Чтение и
запись выполняются через контекстный менеджер `with`; отсутствующий или
повреждённый файл обрабатывается исключениями и не прерывает работу программы.

**Перечень функций, реализованных на ПР2:**

  `create_registration`, `next_id`, `next_registration_id`;

* проверка доступности и расчёт мест — `is_event_available`,
  `count_active_registrations`, `count_registrations_by_status`,
  `get_free_places`, `is_event_full`, `get_event_status`;
* решение по заявке (сценарий ПР1, переработанный) — `check_requirements`,
  `get_registration_result`, `generate_ticket_code`, `get_availability_text`;
* подтверждение и отмена — `confirm_registration`, `cancel_registration`;

## Результат работы

В результате выполнения ПР2:

* завершены темы раздела 01 «Основы Python» (коллекции, итерации и циклы) и
  выполнен раздел 03 по темам «Python: новый уровень» и «Расширенные возможности
  Python»;
* начальный сценарий ПР1 не удалён, а переработан: решение по заявке принимает
  функция `get_registration_result()` модуля `registrations.py`, данные берутся
  из коллекций проекта; демонстрация воспроизводит результат ПР1 — 24
  подтверждённых участника из 25 мест;
* код проекта разделен на восемь модулей по смыслу предметной области, добавлены
  каталог `data/` и каталог `tests/`;
* данные переведены в JSON-файлы, загружаются при запуске и сохраняются при
  выходе из меню;
* реализованы новые функции: обработка коллекций, проверка доступности,
  добавление и отмена регистраций, поиск, сортировка и статистика; меню
  приложения расширено до 13 пунктов, добавлена возможность создавать клубы,
  темы и мероприятия;
* реализована обработка исключений: `ValueError`, `TypeError`, `KeyError`,
  `FileNotFoundError`, `json.JSONDecodeError`, `OSError` для файлов и
  `EOFError`, `KeyboardInterrupt` при прерывании работы пользователем;
* добавлены аннотации типов к сигнатурам основных функций и документирующие
  строки к каждому модулю и функции;
* выполнена проверка кода линтером `flake8`: замечаний нет;
* создано 159 автоматических тестов в восьми файлах каталога `tests/`, все тесты
  проходят; тесты проверяют как чистые функции коллекций, так и сценарии меню и
  сохранение данных во временном каталоге;
* выполнена отладка программы с помощью отладчика IDE: установлены точки
  останова, выполнен пошаговый прогон с прослеживанием значений коллекций,
  найдена и исправлена ошибка чтения данных JSON;
* файл `README.md` обновлён: добавлены разделы о текущем состоянии проекта,
  применённых возможностях Python, меню, формате данных, структуре и командах;
* результат зафиксирован в Git и отправлен в удалённый репозиторий.

## Вывод

Практическая работа выполнена полностью. Индивидуальный проект переведён с
одного сценария на функциональную консольную программу, работающую с
множеством клубов, тем, мероприятий и регистраций; при этом логика принятия
решения по заявке, созданная на ПР1, сохранена и развита.

Освоенные возможности Python — коллекции, циклы, функции, генераторы,
lambda-функции, модули, исключения, файлы, контекстные менеджеры,
интроспекция и аннотации типов — применены в проекте осмысленно: генераторы
использованы для отбора мероприятий и тем, lambda-функции — как ключи
сортировки, интроспекция — для самодоступного описания состава модулей.
Проверка `flake8` завершается без замечаний, 159 тестов `pytest` подтверждают
работу функций, а данные приложения сохраняются между запусками.

Проект подготовлен к ПР3: структура данных продумана, функции аккуратно
оформлены, задокументированы и покрыты тестами, поэтому переход к классам и
объектам (Club, Topic, Event, Registration) потребует переноса логики без
изменения интерфейса приложения. Декораторы, отложенные на ПР3, будут
применены для повторяющихся операций — проверки доступности и оформления
карточек.
