# Ответы на контрольные вопросы ПР1

## По материалам Яндекс Практикума

**1. Какие основные типы данных используются в Python?**

* `int` — целые числа: `25`, `-7`.
* `float` — числа с плавающей точкой: `3.14`.
* `str` — строки (текст): `"Дебаты"`.
* `bool` — логический тип: `True`, `False`.
* `NoneType` — специальное значение `None` (отсутствие значения).

**2. Чем отличаются int, float, str и bool?**

Это разные типы данных, различаются набором операций и хранимым
представлением. `int` и `float` — числа, но `int` хранит целое, а `float` —
дробное; при делении `7 / 2` получается `3.5`, а `7 // 2` — `3`. `str`
хранит последовательность символов, и операция `+` для строк означает
конкатенацию, а не сложение. `bool` принимает только два значения и
результатом любого сравнения является `bool`. В Python эти типы нельзя
смешивать в арифметических операциях без явного преобразования.

**3. Для чего используется преобразование типов?**

Чтобы привести значение к нужному типу, когда данные приходят в неявном виде.
Например, `input()` всегда возвращает строку, поэтому для вычислений нужен
`int(age_text)`. Преобразование также используется при выводе: `str(25)`
превращает число в текст. Преобразование выполняется функциями `int()`,
`float()`, `str()` и `bool()`.

**4. Какие операции можно выполнять со строками?**

* конкатенация — `+`;
* повторение — `*`;
* извлечение символа — `[0]`, срез — `[2:5]`;
* поиск — `in`, `.find()`, `.index()`;
* проверка — `.startswith()`, `.endswith()`;
* изменение регистра — `.upper()`, `.lower()`;
* удаление пробелов — `.strip()`;
* проверка цифр — `.isdigit()`;
* длина строки — `len()`.

**5. Какие операторы сравнения используются в Python?**

`==` (равно), `!=` (не равно), `<` (меньше), `>` (больше), `<=` (меньше или
равно), `>=` (больше или равно). Результат сравнения — логическое значение
`True` или `False`.

**6. Для чего используется конструкция if?**

Для условного выполнения блока кода: если условие истинно, выполняется тело
конструкции, иначе — следующий за ним код. Это основной способ ветвления
программы.

**7. В чём различие между if, elif и else?**

`if` проверяет первое условие, `elif` — дополнительные условие, если
предыдущие не сработали, `else` задаёт вариант, когда не выполнилось ни одно
из условий. Блоки `elif` и `else` необязательны. В цепочке `if-elif-else`
выполняется только первая подходящая ветка.

**8. Как записываются составные условия?**

Несколько условий объединяются логическими операторами: `and` (логическое
«и»), `or` (логическое «или»), `not` (отрицание). Например:
`if free_places < 3 and age < 18:` — условие истинно, только когда верны оба
признака. В сложных случаях используют скобки для явного задания приоритета.

**9. Для чего используются логические операторы and, or и not?**

* `and` — истинно, только если все операнды истинны;
* `or` — истинно, если хотя бы один операнд истинен;
* `not` — меняет истинность на противоположную.

Они позволяют записывать составные условия в ветвлениях и проверять данные
из формы.

**10. Что такое модуль Python?**

Файл с расширением `.py`, содержащий переменные, функции, классы и другой
код. Стандартная библиотека Python уже содержит готовые модули, например
`datetime` для работы с датой и временем, `random` для генерации случайных
чисел, `math` — для математических операций.

**11. Для чего используется import?**

Чтобы подключить модуль и использовать его объекты в своей программе. Модуль
может быть стандартным, сторонним или собственным файлом проекта.

**12. Чем импорт модуля отличается от импорта отдельного объекта из модуля?**

`import datetime` подключает модуль целиком, и обращение к его объектам идёт
через имя модуля: `datetime.date.today()`. `from random import randint`
подключает только конкретный объект, и вызов идёт сразу по имени:
`randint(1000, 9999)`. Первый способ понятен при чтении кода, второй — короче
записывается. Оба способа применяются в `main.py`.

## По рабочему окружению

**13. Для чего используется виртуальное окружение Python?**

Оно создаёт изолированную среду со своим интерпретатором и набором
пакетов, чтобы зависимости одного проекта не конфликтовали с зависимостями
других проектов или системы. Создаётся командой `python -m venv .venv`,
активируется командой `.venv\Scripts\activate` (Windows) или
`source .venv/bin/activate` (Linux, macOS).

**14. Что такое IDE?**

Integrated Development Environment — интегрированная среда разработки:
программа, объединяющая редактор кода, отладчик, управление версиями и
запуск программ в одном интерфейсе. Примеры: PyCharm, VS Code.

**15. Для чего используется Git?**

Git — система контроля и управления версиями. Она хранит историю изменений
кода, позволяет сравнивать версии, возвращаться к предыдущему состоянию и
работать над проектом нескольким разработчикам.

**16. Что такое репозиторий?**

Репозиторий — хранилище проекта, в котором Git держит полную историю
изменений всех файлов. Бывают локальные (на компьютере) и удалённые
(например, на GitHub). Основные операции: `git add`, `git commit`,
`git log`, `git status`, `git push`.

**17. Что такое commit?**

Commit — зафиксированное изменение в репозитории. Он содержит снимок файлов,
сообщение с описанием изменения, автора и дату. Хеш объекта commit служит его
идентификатором.

**18. Для чего нужен .gitignore?**

Файл, который перечисляет пути и шаблоны файлов, которые не должны попадать
в репозиторий. Обычно это виртуальные окружения, кэш, байт-код Python
(`__pycache__`), файлы IDE и секреты. В проекте исключены папки `.venv/`,
`__pycache__/`, `.pytest_cache/`, файлы `.env`.

**19. Для чего нужен README.md?**

Это первый файл, который открывают при знакомстве с проектом. Он содержит
название, назначение, целевую аудиторию, описание предметной области,
основные сущности, функции, план развития и инструкции по запуску. Файл
является частью репозитория и дополняется по мере развития проекта.

**20. Что такое отладка?**

Отладка — процесс поиска и устранения дефектов в программе. Она включает
воспроизведение ошибки, локализацию её причины, исправление и проверку
результата.

**21. Что такое breakpoint?**

Breakpoint (точка останова) — отмеченная строка кода, на которой выполнение
программы приостанавливается в режиме отладки, чтобы разработчик мог
посмотреть значения переменных в этой точке. В PyCharm ставится кликом слева
от номера строки или клавишей `Ctrl+F8` (в VS Code — `F9`).

**22. Для чего используется пошаговое выполнение программы?**

Оно позволяет наблюдать за работой программы построчно: видеть, какие
строки уже выполнены, какие значения принимают переменные и какая инструкция
приводит к неверному результату. Это основной способ локализации ошибок,
которые невозможно найти при обычном чтении кода.

## По индивидуальному проекту

**23. Какую задачу решает выбранное приложение?**

Приложение автоматизирует управление дискуссионными клубами: ведёт
каталог клубов, тем и мероприятий, принимает заявки участников,
подтверждает их с учётом лимита мест и требований, ведёт учёт посещаемости и
собирает обратную связь. Это заменяет ручную работу в чатах и таблицах.

**24. Кто является предполагаемым пользователем?**

Участники дискуссий (студенты, школьники, взрослые энтузиасты),
организаторы и администраторы клубов, модераторы и спикеры, а также
образовательные учреждения, курирующие внеучебную активность.

**25. Какие основные сущности выделены в предметной области?**

Пользователь (User), дискуссионный клуб (Club), тема дискуссии (Topic),
мероприятие (Event), регистрация (Registration), отзыв или оценка (Feedback).
Связи: у клуба много мероприятий и тем, у мероприятия есть регистрации,
регистрация связывает пользователя и мероприятие.

**26. Какие функции планируется реализовать?**

Регистрация и авторизация, редактирование профиля, просмотр каталога клубов
и мероприятий с фильтрацией, подача заявки на участие и уведомления,
оставление отзывов и оценок, создание и редактирование клубов и тем,
планирование расписания, управление заявками, модерация контента, базовая
аналитика.

**27. Какой сценарий реализован на текущем этапе?**

На ПР1 реализован сценарий «Запись участника на мероприятие дискуссионного
клуба»: программа выводит карточку мероприятия и его статус, считает
свободные места, проверяет требования к участнику (возраст, уровень
подготовки, чтение материалов) и выносит решение по заявке: подтверждение с
выдачей кода участия, лист ожидания или отказ с указанием причины.

**28. Какие конструкции Python использованы в программе?**

Простые типы данных (`int`, `float`, `str`, `bool`), операции, преобразование
типов (`int()`, `str()`), ветвления (`if`, `if-else`, `if-elif-else`,
составные условия, `and`, `or`, `not`), функции с возвратом значений,
импорт модулей (`import datetime`, `from random import randint`), работа со
строками (`.strip()`, `.isdigit()`, `.startswith()`, f-строки, форматирование
кода участника). Классы, коллекции и циклы на этом этапе не используются, они
относятся к ПР2 и ПР3.

**29. Какие части проекта будут добавлены после изучения ООП и Django?**

После изучения ООП сущности проекта (пользователь, клуб, тема, мероприятие,
регистрация, отзыв) будут переписаны в виде классов с наследованием,
инкапсуляцией и полиморфизмом. После изучения Django будет создан
веб-проект: модели и ORM, миграции, база данных, view-функции, шаблоны,
формы, пользователи с аутентификацией и авторизацией, админ-зона, REST API и
контейнеризация в Docker.

**30. Почему выбранная предметная область подходит для дальнейшей реализации в виде веб-приложения?**

Область содержит несколько связанных сущностей с естественными связями, что
прямо соответствует реляционной модели и возможностям Django ORM. Требуются
операции создания, просмотра, изменения и удаления данных (CRUD) для клубов,
тем, мероприятий и регистраций. Нужны пользователи с разными ролями
(участник, модератор, администратор), то есть проверка прав доступа.
Предметная область естественно ложится на веб-интерфейс: каталог мероприятий,
страница записи, кабинет организатора со списком заявок и аналитикой, а API
позволяет отдавать расписание и регистрации внешним клиентам, включая
мобильное приложение или Telegram-бот.
